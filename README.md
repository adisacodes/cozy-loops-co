# Cozy Loops Co🧶

A functional e-commerce web app for a real crotchet business. Customers can browse products, sign in with Google, add items to cart, and place orders.

## Technologies used
- React + Vite
- Tailwind CSS
- Firebase(Auth + Firestore)
- React Router
- Jest and React Testing Library
- Github Actions

## Features 
- Google Authentication
- Browse crotchet products
- Products detail page
- Add to cart
- Place orders
- Order history dashboard
- Deployed with github actions

## Running tests
npm test

## Running locally
npm install 
npm run dev
